# CJ Autoworx

A small browser game about running a chaotic car modification shop.

You manage **CJ Autoworx**: LED/underglow lighting installs and interior mods
(CarPlay retrofits, trim work) for a stream of customers, using a team that is
not, strictly speaking, good at this.

- **You** — the owner, spread thin across everything.
- **Jarrad** — great with lighting, catastrophic with a glue gun.
- **Chris** — solid on interior mods, allergic to doing the tax return.

Assign staff to jobs, keep an eye on cash and reputation, and periodically
send Chris off to do the books before HMRC comes knocking. Somehow, no
matter how badly a job goes, the customers keep showing up — including one
memorable Mercedes Vito that CJ Autoworx will never live down.

## Play

No build step or dependencies — it's a static HTML/CSS/JS page.

```
open index.html
```

or serve it locally:

```
python3 -m http.server 8000
# then visit http://localhost:8000
```
